## Outcome and boundaries

A normal county run resolves the selected county and included cities, reuses current methods, discovers missing sources, verifies supported methods, collects and interprets opportunities, and presents saved candidates or precise coverage limitations. The user must not choose an official seed, write quotations/check instructions, select a parser, or register methods. Manual and scheduled runs use the same durable execution path. No Saline-specific production branching or fixed county allowlist.

This explicitly supersedes the human source/method setup requirement in the parent [Admin plan](admin-county-triggers.md) for this automated county path. It does **not** authorize automatic non-SAM canonical lead imports: collect and stage validated candidates automatically, then retain existing exact import approval, protected-field and reconciliation guards.
