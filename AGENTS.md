We're going to methodically start building out this UI-only prototype for a janitorial lead-generation product.

Only build real integrations if specifically asked for. Clarify if you're not sure if the request should create a particular integration.

When the specifically asked for request involves a database, do not use mock data. You can retain any mock data that currently exists, unless it will now point to the database. Have all mock location-related data be in or near Little Rock, AR.

Queues are entry points, not workflow silos.

After each action, show the next logical action without unnecessary navigation.

Optimize for fewest reasonable clicks, preserved context, and obvious next action.

Information and presentation should be very to-the-point and not verbose. This is because the user needs to be able to make quick, at-a-glance decisions even in bulk.

# BRAND AND VISUAL DIRECTION

The company brand color is:

`#FF914D`

Establish a polished visual system that can be reused throughout the eventual application.

The interface should feel:

* modern
* clean
* professional
* warm
* approachable
* trustworthy
* simple
* appropriate for a small-business owner

Use a clean neutral foundation with generous whitespace.

Use `#FF914D` strategically for:

* principal calls to action
* active/selected elements
* meaningful accents
* important interactive elements where appropriate

Do NOT:

* make everything orange
* use excessive gradients
* create a futuristic "AI" aesthetic
* make the interface look like an enterprise CRM
* overcrowd screens with cards and badges
* make every action equally prominent

Create clear hierarchy between:

**Primary action**

**Secondary action**

**Information**

**History/context**

Accessibility and readable contrast take priority over strict use of the brand color.
