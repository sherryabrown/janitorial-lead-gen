# Phase 5 — Source and geography catalog acceptance

Completed locally on October 22, 2026. Implements the Phase 5 plan using the parent requirements and the completed Phase 3/04A/04B amendments. No commit, push, migration or hosted deployment was performed.

## Result

- Settings now has Sources by geography and Related geography alongside the existing Schedules, History/logs and Stats views. The schedule list, editor, floating actions and five detail tabs retain their behavior.
- Authenticated read-only `GET /v1/admin/sources` and `GET /v1/admin/geographies` reuse the existing workflow transport/authentication, bounded hosted-store reads, `sourceInventory`, `resolveGeography`, registered coverage and `capabilityCoversRoute`/`adapterContract`. Filters include geography, type, category, readiness, search, stable sorting and pagination. Source/category gaps page separately from sources.
- Shared sources count once by source ID while preserving route/category methods and state associations. Sources expose dated method readiness, expiry/inactive/contract blockers, safe official URLs and bounded verification references. Historical access notes are identified as historical rather than published as current credentials. Source-level saved limitations remain distinct from narrow verified methods.
- Latest recorded capture metadata is one bounded batch read for the source page, never a per-row full-history report. Missing records within that window are unknown, not proof of no prior check. A capture-history failure retains the registry with an explicit unavailable basis. Capture outcomes and record counts do not establish successful lead imports or complete category coverage.
- Geography uses actual place/county links, active flags and dataset provenance. Legacy Census `place` rows are excluded from the GIS municipality presentation, avoiding duplicate names without altering any stored row. Multi-county municipalities retain all registered county memberships, including Little Rock and Tull. State-source cities are explicitly derived from county links, not asserted agency service or work-site coverage. SAM remains an independent statewide target.
- Schedule Related geography retains its saved snapshot and adds a current registry catalog, immutable selection-token comparison and added/removed memberships. Grouped state schedules show saved/current county associations and missing saved association IDs. Sources retains the existing selected-run evidence and adds an expandable, separately labeled current registry. Registry reads never imply a source was checked in the selected historical run.
- Reused ReadAction/useOwnedRead keeps one visible Refresh/Retry owner. Global catalogs own their toolbar; embedded catalogs register with the schedule workspace. Filters/pages remain owner/scope-specific; source/geography identities round-trip in validated navigation URLs. Back restores the identifying row, and sign-out clears that owner's catalog state. Obsolete reads are aborted/ignored, new filters do not display old-scope rows, and same-scope Refresh failures retain loaded content.
- No new source/geography editing, account access, search provider, collection adapter, scheduling behavior, import decision or AI work was introduced. Registry/geography GETs do not wake workers. Existing source evidence/import actions and manual state controls remain explicit.
