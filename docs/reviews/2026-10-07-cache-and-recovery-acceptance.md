## Scope and implementation

The user approved a focused change for portable verified supporting facts. Reuse requires a signed private receipt, the same source/method/version/specification and identical primary listing URLs/hashes. Supporting bytes, current official-host policy, method validity and literal quotations are checked again. Each request still checks geography and its date basis/window. The server issues a new packet-bound receipt recording its original capture and reuse; original retrieval time is preserved. Historical evidence is not represented as a fresh supporting-document fetch or as full lead coverage.

`supporting-capture.mjs` signs and rebinds portable receipts. `hosted-interpretation.mjs` caches server-verified supporting references and replaces an exactly reviewed raw row rather than retaining it as an ambiguous duplicate. `hosted-workflow.mjs` verifies supporting facts before applying request bounds. Unverified or changed evidence remains unresolved; other ambiguous rows retain current AI behavior. No new table, migration, adapter, AI option or frontend was added.
